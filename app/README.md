# Galaxy Brain application project

This directory contains the Galaxy Brain desktop Knowledge Workbench project. It is the application namespace, not part of the user's portable Knowledge Repository.

- `docs/`: architecture, ADRs, engineering and agent guidance, proposals, and review records for the application
- `prototype/`: temporary, disposable GUI explorations
- future application source, dependencies, build output, and UI assets belong here with the application code

The application may open a user-selected Knowledge Repository, but application releases and source changes must not require changes to the repository's knowledge files.
