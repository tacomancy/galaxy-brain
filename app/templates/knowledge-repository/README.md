# Galaxy Brain Knowledge Repository

This is an empty starter for a private Knowledge Repository. Galaxy Brain reads and writes the portable files here without requiring Git, Git LFS, GitHub, credentials, network connectivity, or Agent Provider configuration. You may initialize and manage Git externally if you want version control and backups. Agentic Capabilities remain unavailable until the Workbench has an optional provider configuration.

The Repository Format is declared in `galaxy-brain.yaml`. The optional `.gitattributes` file is a convenience for users who choose to configure Git LFS externally for managed PDFs.

## Directories

- `assets/`: repository-managed Source Assets
- `knowledge/`: reviewed Governed Knowledge
- `projects/`: project Working Material
- `proposals/`: proposals and applied audit records
- `scratch/`: provisional Working Material
- `sources/`: source notes and annotations
- `templates/`: approved note templates
