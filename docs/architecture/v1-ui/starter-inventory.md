# Tracer Bullet 2 starter inventory

This inventory is the checked-in record of the public V1 starter skeleton. It
contains structure and reusable blank templates, not subject-matter knowledge.
The contract test keeps an independent path snapshot so an intentional starter
change must update both the skeleton and this record in the same review.

## Repository metadata and policy

- `galaxy-brain.yaml` — scalar format declaration.
- `.gitattributes` — optional user-managed text policy.
- `README.md` — repository orientation.
