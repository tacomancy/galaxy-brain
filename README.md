# galaxy-brain

A human-owned knowledge base for personal research and continuing education. Agents are helpers: they may research, organize, test, and propose, while the user remains the primary author, learner, and authority over core knowledge.

## Structure

- `knowledge/`: reviewed, approval-gated core knowledge
- `sources/`: source-bound notes and annotations
- `projects/`: goal-bound applications of knowledge
- `scratch/`: low-friction provisional thinking
- `proposals/`: exact changes awaiting human review
- `templates/`: lean starting points for notes
- `assets/`: lightweight visuals and reusable source assets
