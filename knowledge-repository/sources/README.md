# Sources

Store working notes and annotations organized around a specific book, PDF, class, course, paper, website, or other source here. Source-bound notes preserve what that source claims; synthesis that represents finalized, reviewed understanding belongs under `knowledge/`.

Create source notes from `templates/source.md` under `books/`, `courses/`, `papers/`, or `web/`.

Repository-managed source files belong under `assets/`; source files intentionally kept elsewhere remain externally located according to the accepted storage policy.
