# Galaxy Brain project documentation

This directory contains documentation about the Galaxy Brain project and its desktop Knowledge Workbench. It is not part of the knowledge base.

Use it for architecture, ADRs, engineering and agent guidance, application design proposals under `app/docs/proposals/`, review records under `app/docs/reviews/`, and other durable project documentation. Knowledge-base content belongs under `knowledge-repository/assets/`, `knowledge-repository/knowledge/`, `knowledge-repository/projects/`, `knowledge-repository/proposals/`, `knowledge-repository/scratch/`, `knowledge-repository/sources/`, or `knowledge-repository/templates/` according to its role and lifecycle.

The application may read or write a user-selected Knowledge Repository, but project documentation must not become repository content merely because this development checkout co-locates both concerns.
