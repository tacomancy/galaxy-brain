# Local Knowledge Repository

This directory is the development checkout for the user's local Knowledge Repository. Its contents are knowledge-base material, not Galaxy Brain application documentation or source code.

- `assets/`: repository-managed images, reference documents, and other supporting files
- `knowledge/`: finalized, reviewed core knowledge
- `projects/`: working notes for a specific project or outcome
- `proposals/`: proposals to change governed knowledge-base content
- `scratch/`: miscellaneous provisional knowledge notes
- `sources/`: notes and annotations for books, PDFs, classes, papers, websites, and other sources
- `templates/`: templates and snippets for new knowledge-base files

The application project is outside this directory under `app/`. The directory name `knowledge-repository/` is a development-checkout boundary; the repository's internal roots remain portable if the Knowledge Repository is copied or opened independently.
