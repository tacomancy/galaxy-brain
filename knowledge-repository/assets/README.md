# Assets

Store files managed as part of the knowledge base here, including images, diagrams, reference documents, and other knowledge-supporting assets. Keep related notes and annotations under `sources/`, `projects/`, or `knowledge/` as appropriate rather than treating an asset file as the note itself.

Files intentionally kept elsewhere remain external and are referenced through portable Source Records. Follow the accepted storage policy before adding large files. Application icons, bundled UI media, and other Workbench-owned assets belong with application code, not in this directory.
