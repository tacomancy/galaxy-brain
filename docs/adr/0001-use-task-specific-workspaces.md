# Use task-specific workspaces

The V1 Knowledge Workbench will use three explicit workspaces—Atlas for orientation and judgment, Studio for authoring and synthesis, and Paper Desk for source processing—rather than one universal or automatically morphing interface. A compact global switcher and contextual transitions will preserve continuity between them; the added navigation cost is accepted in exchange for predictable interfaces tailored to materially different jobs.
