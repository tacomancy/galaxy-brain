# Knowledge workbench UI prototype

> Throwaway prototype. This is not production code or the canonical knowledge interface.

This prototype compares three interaction models on one route:

- `A`: editor-first research studio
- `B`: dashboard-first knowledge atlas
- `C`: source-first paper desk

Run:

```bash
python3 prototype/knowledge-workbench/serve.py
```

Then open <http://127.0.0.1:4173/>. Switch variants with the floating controls, the left/right arrow keys, or `?variant=A`, `?variant=B`, and `?variant=C`.
