# Govern changes through proposals

All changes to Governed Knowledge, whether manually authored or agent-assisted, go through a Proposal reviewed against an exact version. Agents may create attributed Working Material and users may manually create Proposals from it without an Agent Provider. Governed Knowledge remains editable through new reviewed versions; opening it for editing creates a Working Material draft rather than mutating the current version. This trust boundary adds deliberate friction and a review interface, but preserves human authority, makes evidence and uncertainty inspectable, and prevents either polished agent output or an unreviewed local edit from silently becoming accepted knowledge.
